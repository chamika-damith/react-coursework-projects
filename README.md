# Salon Service Booking Website

## 🏠 Project Overview
This is a **Salon Service Booking Website** that allows clients to book services online and provides an admin dashboard for managing appointments, services, and users. The project is built using modern web technologies with a **Node.js & Express** backend and a **React** frontend.

## 🚀 Tech Stack
### **Frontend:**
- React
- Axios
- Tailwind CSS

### **Backend:**
- Node.js
- Express.js
- Prisma ORM
- MongoDB

### **Other Dependencies:**
- JWT for authentication
- Bcrypt for password hashing
- Dotenv for environment variables

---

## 🔧 Features
### **Client Features:**
- User registration & authentication (JWT-based login/logout)
- Browse available salon services
- Book appointments
- View booking history

### **Admin Dashboard Features:**
- Manage salon services (Add, Edit, Delete)
- Manage appointments
- Manage users (clients)

## ⚙️ Installation & Setup

### **1️⃣ Clone the Repository**
```sh
git clone https://github.com/chamika-damith/react-coursework-projects
```

### **2️⃣ Backend Setup**
```sh
cd salon-booking-backend
npm install
```
#### **Environment Variables:**
Create a `.env` file in the backend directory and add the following:
```env
PORT=3000
DATABASE_URL=mongodb+srv://your-db-url
JWT_SECRET=your-secret-key
```
#### **Run Backend Server:**
```sh
npm start
```

#### **Run Frontend Server:**
```sh
npm run dev
```
